# 术语表：先知道这些词指什么

术语只是给一个概念起名字。先抓住每个词解决的问题，再去看实现。下面按模块归类；点击“继续阅读”可以看到完整例子。

## 模型与执行循环

| 术语 | 通俗解释 |
| --- | --- |
| Agent，智能体 | 围绕目标反复判断、行动、读取反馈的整个系统 |
| LLM，大语言模型 | 根据输入预测并生成输出的模型；调用外部系统要经过程序 |
| Prompt，提示词 | 提交给模型的指令与输入文字 |
| System prompt，系统提示 | 请求中用于说明角色与规则的消息，不是操作系统权限设置 |
| Token，词元 | 模型处理文本的计量单位，不严格等于一个汉字或一个单词 |
| Tokenizer，分词器 | 把文字转换成 token 的具体规则或程序 |
| Message，消息 | 一条带角色与内容的输入，如 user、assistant、tool |
| Tool calling，工具调用 | 模型用结构化输出提出工具名和参数 |
| ReAct | 推理与行动交替、利用外部结果继续决策的一种组织方式 |
| Observation，观察结果 | 工具实际执行后的返回内容，包括成功结果和错误 |
| Loop，执行循环 | 请求模型、执行工具、回填结果、检查终止的重复过程 |
| Workflow，工作流 | 由程序或配置安排步骤，模型完成其中部分环节 |
| Model routing，模型路由 | 根据配置、用途或状态选择模型与供应商 |

继续阅读：[Agent 全景](01-agent-overview.md)、[模型与循环](02-models-and-loop.md)。

## 工具与协议

| 术语 | 通俗解释 |
| --- | --- |
| Tool，工具 | 程序实现的一项外部能力，名称相同不代表执行位置相同 |
| Schema，结构约束 | 对输入字段、类型、必填项等的说明 |
| JSON | 用对象、数组、字符串等表示结构化数据的格式 |
| Executor，执行器 | 校验调用并实际运行工具的程序 |
| Side effect，副作用 | 对外部状态的修改，如写文件、创建工单、发送消息 |
| Dependency，依赖 | 一步必须先拿到另一步结果才能执行 |
| Concurrency，并发 | 多项工作在时间上重叠推进，不要求每时每刻都占用不同 CPU |
| MCP | 统一工具和上下文能力接入方式的协议 |
| Host | 承载模型、用户交互与工具连接的应用 |
| Client | 代表 Host 连接某个工具服务的协议端 |
| Server | 接收协议请求并提供能力的程序 |
| Capability，能力声明 | 声明协议端支持哪些功能，不能代替具体操作授权 |
| Transport，传输方式 | 协议消息通过什么通道传送，如进程管道或 HTTP |
| stdio | 通过子进程标准输入、标准输出交换消息 |
| RPC，远程过程调用 | 向另一端发请求，让另一端执行方法并返回结果 |
| Skill | 某类任务的说明、步骤与参考知识，通常按需加载 |

继续阅读：[工具编排](03-tools-and-orchestration.md)、[MCP](07-mcp.md)、[Skills](08-skills.md)。

## 上下文、检索与记忆

| 术语 | 通俗解释 |
| --- | --- |
| Context，上下文 | 模型本次请求实际看到的信息；和 Go 的 context.Context 不是同一个概念 |
| Context window，上下文窗口 | 模型一次可处理内容的容量限制 |
| Transcript，完整记录 | 系统保存的原始对话和工具结果 |
| View，模型视图 | 从完整记录中选出、本次真正发给模型的内容 |
| Trim，裁剪 | 按规则移除部分历史，通常优先移除旧内容 |
| Truncate，截断 | 缩短某一条长内容，不一定删除整条消息 |
| Summarize，摘要 | 把一段历史改写成更短的说明，会有信息损失 |
| Prompt cache，提示缓存 | 供应商复用相同输入前缀的计算；不是长期记忆 |
| RAG，检索增强生成 | 先取回外部资料，再让模型结合这些资料回答 |
| Chunk，片段 | 可被检索的一个文本单位，如一段制度说明 |
| Metadata，元数据 | 描述片段的编号、标题、时间、来源、权限等 |
| Embedding，向量表示 | 把文本编码成一组数字，用于比较语义关系 |
| Vector，向量 | 一组有顺序的数字；不能直接当作事实交给聊天模型 |
| Similarity，相似度 | 衡量两个表示有多接近的分数，不是答案正确概率 |
| 余弦相似度 | 比较向量方向的接近程度，范围是 −1 到 1 |
| Top-k | 在排序后最多取前 k 个候选，候选不等于有效证据 |
| BM25 | 根据关键词出现、稀有程度与文本长度进行排序的方法 |
| RRF | 依据多个检索列表的名次融合结果，避免直接相加不同量纲的分数 |
| Rerank，重排 | 对已经召回的少量候选做更细致的相关性判断 |
| Contextual Retrieval | 给孤立片段补充来源背景，再建索引帮助检索 |
| Provenance，来源依据 | 一条信息原本来自哪条记录、哪份材料、哪个时间 |
| Working memory，工作记忆 | 当前任务中通过上下文使用的信息 |
| Long-term memory，长期记忆 | 可跨独立会话选择性保存、读取、更新的状态 |
| TTL，生存时间 | 一条数据保存或生效多久，过期后应停止当作有效信息 |
| Cache invalidation，缓存失效 | 原文或配置变化后，让过时派生数据不再被使用 |

继续阅读：[上下文](04-context-management.md)、[检索](05-retrieval-rag.md)、[记忆](06-memory.md)。

## 运行时、恢复与调度

| 术语 | 通俗解释 |
| --- | --- |
| Runtime，运行时 | 执行期间管理预算、状态、取消与资源的程序层 |
| Retry，重试 | 再尝试同一个操作，先判断是否安全且可能有效 |
| Backoff，退避 | 每次重试前等待一段时间，常让等待逐步增加 |
| Jitter，抖动 | 在等待时间里加入随机变化，避免大量请求同时重试 |
| Circuit breaker，熔断 | 达到异常条件后主动停止继续尝试 |
| Timeout，超时 | 达到等待时限；不证明外部操作没有成功 |
| Deadline，截止时间 | 最晚应结束的绝对时间，下层不能超过上层截止时间 |
| Cancellation，取消 | 请求停止继续工作；不自动撤销已经发生的动作 |
| Go context.Context | 向下传递取消、截止时间等信号的 Go 对象，不是模型消息历史 |
| Unknown，结果未知 | 操作可能已发生，但当前程序没有拿到可信结果 |
| Checkpoint，检查点 | 保存到哪里了、已有结果是什么、下一步从哪里继续 |
| Write-ahead log，写前日志 | 执行前先记录意图，崩溃后能看见可能有未确认动作 |
| Atomicity，原子性 | 对外只呈现完整的旧状态或新状态，不出现半份更新 |
| Lock，锁 | 保证关键区域在同一时间只有合适的执行者修改状态 |
| Queue，队列 | 保存等待执行的任务，由执行者逐个领取 |
| Worker，执行者 | 从队列取任务并执行的程序或工作单元 |
| Lease，租约 | 在有限时间内拥有处理某任务的权利，超时可重新分配 |
| Idempotency，幂等 | 同一个逻辑操作执行多次，业务效果与执行一次相同 |
| Idempotency key，幂等键 | 标识同一个业务意图，由产生副作用的一端识别并去重 |
| Dead-letter queue，死信队列 | 收纳多次失败、暂不再自动处理的任务 |
| Subagent，子 Agent | 父 Agent 委派的另一个有自己上下文和循环的 Agent |

继续阅读：[运行时](09-runtime-reliability.md)、[恢复](10-checkpoints-and-recovery.md)、[调度](11-task-scheduling.md)、[子 Agent](12-subagents.md)。

## 浏览器、安全与观测

| 术语 | 通俗解释 |
| --- | --- |
| DOM | 浏览器把页面组织成的结构树 |
| CDP | 程序控制 Chrome 等浏览器的调试协议 |
| Shell | 接收命令并启动程序的命令解释器 |
| Sandbox，沙箱 | 用操作系统机制限制程序看得到、做得到和用得起的资源 |
| Namespace | 给进程不同的系统视图，如不同的网络或进程列表 |
| cgroup | 对一组进程设置 CPU、内存、任务数量等资源限制 |
| seccomp | 限制进程可使用的系统调用 |
| Syscall，系统调用 | 程序向内核请求能力的接口，例如建立连接、创建进程 |
| BPF | 一种可被内核使用的小程序格式，经典 BPF 可表达 seccomp 过滤规则 |
| Least privilege，最小权限 | 只授予完成当前动作所需的权限 |
| SSRF | 让运行在服务端的工具代访问本机、内网或其他受保护地址 |
| Prompt injection，提示词注入 | 把不可信内容伪装成指令，诱导模型改变任务或泄露信息 |
| Egress，外发通道 | 能把数据送到系统外部的连接，如浏览器请求或发送消息 |
| Observability，可观测性 | 用记录、关联关系与指标理解系统发生了什么 |
| Trace，调用轨迹 | 按关联 ID 串起一次任务的模型、工具及子任务过程 |
| Span，执行片段 | 轨迹中一个有起止时间的操作，如一次检索 |
| Metrics，指标 | 把很多次运行汇总成的数值，如成功率、耗时分布 |
| Turn，用户回合 | 一次用户提问及相关执行过程 |
| Step，任务步骤 | 用户回合内的一次任务模型调用及其工具执行 |
| Evaluation，评估 | 根据事先定义的目标和检查方式判断效果 |
| Recall，召回率 | 应找到的相关资料中，实际找到了多少 |
| Precision，精确率 | 取回的资料中，真正相关的占多少 |

继续阅读：[浏览与执行](13-browser-and-execution.md)、[安全](14-security-and-isolation.md)、[观测与评估](15-observability-and-evaluation.md)。

## 技术展开中的术语

| 术语 | 通俗解释 |
| --- | --- |
| 状态机 | 用状态及允许的转换描述执行过程 |
| 不变量 | 任何分支都不能破坏的条件 |
| 契约 | 输入、输出、错误和权限应遵守的约定 |
| 控制面 / 执行面 | 决定是否行动 / 实际运行行动的部分 |
| 消息闭包 | 调用请求及其全部结果一同存在，配对完整 |
| Opaque field | 不能随意解释或修改、需要按协议保留的字段 |
| Delta | 流式响应分批到达的一段增量 |
| Adapter | 转换不同协议、供应商或数据格式的程序 |
| json.RawMessage | Go中用于暂存一段JSON的类型，不自动保留未声明字段 |
| EOF | 输入流已结束，能用于检查JSON后是否还有内容 |
| DAG | 描述前后依赖的有向无环图 |
| 信号量 | 限定同时进入执行区域的许可 |
| 背压 | 消费方繁忙时限制上游继续积累 |
| 规范化 | 把不同表示按规则转换，便于比较，但不自动等于业务等价 |
| 校准 | 用真实用量修正本地估算 |
| 滞回 | 触发阈值与处理后目标分开，避免频繁来回处理 |
| 保留区 | 不参与本次历史摘要的规则、原话和最近完整组 |
| 倒排索引 | 从词项找到包含它的片段和词频 |
| TF / DF | 片段中某词出现次数 / 包含该词的片段数量 |
| IDF | 给稀有词更高权重的区分力计算 |
| 模型空间 | 某个向量模型定义的坐标语义，维度一样也不保证兼容 |
| Cross-encoder | 把问题与候选一起编码，直接判断关联的模型 |
| ANN | 近似最近邻检索，以一定召回损失换大规模搜索速度 |
| 快照 | 某一时刻取得的状态，后续可能不再最新 |
| 内容指纹 | 原文、来源与配置的稳定哈希，用于识别派生数据是否匹配 |
| 乐观提交 | 在锁外做慢计算，提交前检查原始状态没有变 |
| 半衰期 | 每经过该段时间，衰减权重减少到一半 |
| Wire message | 实际在传输通道中发送的报文 |
| Transport / protocol / tool error | 传输未确认 / 协议不合法 / 工具业务失败 |
| Registry | 可信名称到位置或执行连接的登记表 |
| Version pinning | 一次任务固定使用某版正文或资源 |
| TOCTOU | 检查与实际使用之间，目标发生变化的竞态 |
| Trusted root | 允许访问的资源目录边界，不是其中全部内容的可信证明 |
| YAML | 常用于配置的数据表达格式，用缩进等规则组织字段 |
| 逻辑调用 / attempt | 模型提出的一项动作 / 执行器的一次尝试 |
| 未知结果窗口 | 外部开始处理到程序取得可信结果之间 |
| 耐久性 | 已提交状态按存储契约承受断电等故障的能力 |
| fsync / Sync | 请求同步内容，文件数据与目录项需要区分 |
| 事务边界 | 哪几项更新一起成为可见的新状态 |
| 日志粒度 | 按整任务、整批还是每项调用保存过程 |
| Fencing token | 新执行权使用更高代号，结果端拒绝旧持有者写入 |
| 吞吐 / 利用率 | 单位时间完成量 / 可用执行能力被占用的比例 |
| 委派契约 | 子任务的目标、输入、约束、权限与交付要求 |
| 聚合预算 | 父任务加所有子任务的共同成本上限 |
| Remote object | 浏览器脚本求值返回的协议对象，不一定就是正文 |
| ABI | 程序与系统的调用约定，包括编号的解释规则 |
| 经典BPF | seccomp可以使用的受限过滤程序格式，区别于任意eBPF程序 |
| 文件描述符 | 进程持有的文件、管道或连接句柄，也可能形成继承能力 |
| Fail-open / fail-closed | 边界无法建立时继续 / 明确拒绝执行 |
| 连接绑定 | 实际连接使用已检查的地址，避免再次解析改变目标 |
| 事件账本 / 输入快照 | 真正发生的事件 / 本次提交的完整输入 |
| 统计单位 | 一次任务、请求或尝试等被计数对象 |
| 留出集 | 没参与调试，用来检查泛化效果的数据 |
| 置信区间 | 在统计前提下表达样本估计的不确定范围 |
| Wilson区间 | 对成功/失败样本计算比例不确定范围的方法 |
| 指标基数 | 指标标签组合数量，无限变化的任务ID会让它持续增加 |
| TTFT | 请求开始到首个模型token的时间，不能由非流式总耗时倒推 |
